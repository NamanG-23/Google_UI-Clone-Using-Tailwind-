# Google_UI-Clone-Using-Tailwind-
A responsive Google search homepage UI built using HTML and Tailwind CSS. It's my first project built using Tailwind CSS


##  Features
- Basic Google homepage layout
- Responsive design for different screen sizes
- Dark mode toggle option
- Utility-first styling with Tailwind CSS
- Minimal and clean look

## Tech Stack
- HTML
- Tailwind CSS

##  Learning Purpose
This project is not an official Google product.  
It is just a practice project to learn Tailwind CSS and improve my frontend development skills.  
The focus was on understanding how Tailwind utilities work and how to build a neat, responsive UI.
